## Frequently Asked Questions

**Q: Is this toolkit compatible with Windows Server operating systems?**
A: While primarily designed for Windows 10 and 11 client operating systems, it is generally compatible with Windows Server 2016, 2019, and 2022 for administrative scanning tasks.

**Q: Why can't the scanner see some of my devices?**
A: Ensure that ICMP (ping) is not blocked by the device's firewall. Also, verify that your scanner has the necessary network credentials (SNMP community string, WMI/Admin shares) to query devices for detailed information.

**Q: Does this tool require administrator rights to run?**
A: Basic ping scans work with standard user rights. However, to utilize advanced features like WMI enumeration, remote service management, and full asset inventory, you must run the application as an Administrator.
